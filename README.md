# დუელი

ორი მოთამაშის ონლაინ რბოლა. ერთი ქმნის ოთახს და ირჩევს, რამდენ ქულაზე ითამაშებენ, მეორე ბმულით შედის. ტრასა ყოველ ჯერზე სხვაა, მაქსიმუმ 2 წუთი გრძელდება.

## ფაილები (ყველა ერთ დონეზე უნდა იყოს საცავის მთავარ გვერდზე)

`server.js`, `package.json`, `render.yaml`, `index.html`, `style.css`, `game.js`, `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png`, `logo.svg`, `test.js`, `README.md`. სულ 13 ფაილი.

## გამოქვეყნება (Render, უფასო)

1. GitHub-ზე შექმენი ახალი საცავი, მაგალითად `duel`, და ატვირთე ყველა ფაილი (**Add file → Upload files → Commit changes**).
2. render.com: **New → Web Service**, აირჩიე საცავი. Runtime: **Node**, Build: `npm install`, Start: `npm start`, Instance: **Free**.
3. გახსენი მიღებული ბმული, მეგობარს გაუგზავნე.

## წესები

- ყველას 10 ქულა აქვს (ვირტუალური). ქულები ინახება თითოეული მოწყობილობის ბრაუზერში.
- მოგებული იღებს ფსონს, წაგებული კარგავს. მანქანა 42 000 ქულაა: ჯერ მხოლოდ კონტურია, ყოველი 10 ქულა ერთ უჯრას ღებავს.
- ნიტრო ⚡ ძალიან აჩქარებს, სანამ არ გაითავდება. 🚀 აფეთქებას უგზავნის მოწინააღმდეგეს. სიჩქარე: საშუალო, სწრაფი, სუპერ სწრაფი.

## ჯილდო

თამაშში უფასოა და ფულის ჩადება არ სჭირდება. რეალური ჯილდოს (მაგალითად მანქანის) გათამაშებამდე გადაამოწმე კანონმდებლობა. ტექსტი, რომელიც სრულად შეღებილ მანქანაზე ჩანს, იცვლება `game.js`-ში, ხაზზე `PRIZE_TEXT`.

## ცნობილი შეზღუდვა

ტესტ-ვერსიაში ქულებს ბრაუზერი ინახავს, ამიტომ ჭკვიან მოთამაშეს შეუძლია ისინი შეცვალოს. რეალური ჯილდოსთვის ანგარიშები სერვერზე უნდა ინახებოდეს.
